Where this key goes, and the risks

The key is sent only to api.openai.com, direct from your browser. There is no server in this app and nothing is logged anywhere.

It is held in page memory while the app runs, so any script injected into this page could read it. There are no third-party scripts, no fonts or analytics from other origins, and a Content-Security-Policy that permits network calls to OpenAI only.

If you pick “This device”, read this. Every project published under yourname.github.io shares one browser origin, so any other page you have ever hosted there can read the saved key. That is why “Don’t remember” is the default. A custom domain or a dedicated account avoids it.

The CSP stops a third party being contacted, but someone who managed to inject script could still exfiltrate through OpenAI itself. The real mitigation is scope: create a dedicated project, issue a key with a spend limit, and revoke it when you are done. Manage keys

Source caption accuracy

The translator accepts no glossary, so the source transcript comes from a second pass that does. Both run at once and both cost money.

Topic measurably helps with names and part numbers. Keywords are accepted by the API but never echoed back in the session, and made no difference in testing — put your jargon in Topic.
